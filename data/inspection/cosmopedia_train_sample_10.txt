The SST dataset is available in three parts: training, validation, and testing. Each part is stored in a separate CSV file, with columns for the review text (`sentence`) and its sentiment label (`label`).

To load the dataset, we will define a function called `load_sst()`. This function takes the path to the CSV file as input and returns two lists: `X`, which contains the review texts, and `Y`, which contains the sentiment labels.

```python
import pandas as pd

def load_sst(path):
    """
    Loads SST binary dataset into inputs and labels

    Args:
        path (str): the location of the dataset

    Returns:
        X (list): the reviews
        Y (list): the scores of each review
    """
    data = pd.read_csv(path)
    X = data['sentence'].values.tolist()
    Y = data['label'].values
    return X, Y
```
